# MSC converter test audit

Baseline: MSC `5f3767d`. The original audit was tests-only. The subsequent MSC-TEST-001 correction below changes generated chemistry annotations; consumer repositories, existing run state and release pins remain untouched.

## Findings and decisions

The old public e2e test checked serialization against its own returned packages and mainly checked MAGE-TAB file existence. Its H5AD companion protected lazy imports but did not assert complete scientific output. There was no independent stored-output case for each converter. Import/callability and private inheritance checks overstated workflow assurance; the checkpoint version test generated paths without writing checkpoints.

The first implementation unit adds independent converter and CLI contracts, raw source evidence, reviewed outputs, corruption checks and byte-preserving checkpoint tests. See [fixture provenance and review](fixtures/README.md). The second unit consolidates only superseded or overstated tests. Focused mock-based tests remain where they exercise flags, error propagation, policy forwarding or provider failures. A mock is not itself a reason to delete a test.

## Scope and retained coverage

The inventory below classifies existing tests in converters, expression, MAGE-TAB, metadata, sources, CLI, JSON loading, service boundaries, public e2e, and documentation policy. `retain` means no deletion was justified by this audit; it does not claim each test independently covers an end-to-end scientific contract. MINiML model/codec/patch, XML safety, request policy, artifact publication and runtime contract suites remain unchanged and continue to supply necessary coverage. Consumer-wide test rewrites are outside scope.

Retained branch coverage includes asset precedence, memory admission, interruption/resume, invalid-output rejection, permissive diagnostics, overwrite refusal, group failure, restoration/recovery, observation aggregation, optional sidecars, protocol registration order, repeated headers, technology-specific rendering, malformed input, supported envelopes, and CLI status/error behaviour.

## New acceptance evidence

- One independently invoked stored-output case per converter, plus all seven real CLI dispatches.
- Public GEO XML + captured PubMed/SRA/ENA responses; public twelve-row/six-sample MAGE-TAB; four-by-six real PBMC counts. Synthetic cases are explicitly labelled.
- Parent/related traversal cardinality and ordered evidence calls, absent publication and provider errors. GEO JSON intentionally serializes related packages together in one accession-named file.
- Exact matrix values/dtypes, axes, all retained metadata and auxiliary slots; complete table/IDF/SDRF text; exact semantic diagnostics.
- Deliberate count, axis order, identity, dtype, metadata and diagnostic corruption must fail the same comparison helper.
- Old-version checkpoints are written, hashed, retained unchanged across recomputation, and same-version replay is proven by reader call counts.
- Raw-dispatch test invokes the real planner and nf-core orchestration with a bounded fake command runner producing valid counts, then reads and publishes H5AD. It does not validate nf-core computation.
- Documentation import checks now execute import statements rather than merely checking API names appear in prose.

## Defects and limits

**MSC-TEST-001 resolved**: scoped preparation evidence replaces global version detection and fixed read geometry. The former strict xfail is now a normal passing regression in `test_geo_chemistry_regression.py`. New pure-parser and converter tests cover reviewed source excerpts, ambiguous fields, mixed samples, forced handlers, explicit recipes and repeated index retention. The original two MAGE-TAB expectations have a reviewed annotation-only delta documented in fixtures/README.md.

Follow-up dispositions: remove the two fixed-v2/v3-attribute tests because they required invented biology; their replacement exercises all four handler selections against explicit source chemistry and absent unsupported fields. Strengthen the two version-detection tests to require broad droplet selection for unscoped versions. Retain technology dispatch and spatial behavior tests. Existing MAGE-TAB whitespace flattening and semantic column grouping remain unchanged; round-trip tests assert exact ordered comments and published protocol descriptions rather than claiming byte-identical regeneration.

The project-local editable install initially advertised MSC 5.2.1 while importing MSC 6 source. The local installation metadata was refreshed to 6.0.0 before approving provenance expectations. This was an environment defect, not a source change.

A passing offline suite is not proof that live providers or real nf-core executions remain available. Existing optional live tests remain opt-in. Expected files are reviewable contracts, not automatically regenerated approval of current behaviour.

The full-suite diagnostic assertion exposed existing CLI-test logging leakage: package handlers retained a closed pytest capture stream and disabled propagation for later tests. The test harness now restores MSC package handlers, level and propagation after each test, with an exception-path restoration regression. CLI production logging remains unchanged.

Source fixtures and expected tables are excluded from comment-header insertion. Fixture-specific Git attributes preserve original line endings and trailing empty table fields; source bytes and hashes are retained.
